# 國際化

[English](I18N.md)

PureLink 支援 `en` 與 `zh-Hant`。新增語言時只需擴充 `src/i18n.js`；頁面與瀏覽器端程式共用同一份訊息來源。

語言依序由 `purelink_locale` cookie、明確的支援路由前綴、`Accept-Language`、英文預設值決定。`zh-TW`、`zh-Hant-TW`、`zh-HK` 等繁中變體會解析為 `zh-Hant`，英語變體解析為 `en`。

可索引的應用與政策頁採用 `/en/...` 及 `/zh-Hant/...`。根路徑會導向選定語言。既有分享內容刻意不加語言：`/slug` 仍開啟內容，`/slug+` 仍預覽網址目的地。只有完全相符的支援語言名稱是前綴，這些名稱也保留而不可作為新自訂短網址。

語言切換器不需帳號，會以 cookie 保存偏好。可索引的在地化頁面輸出 canonical 與 `hreflang`；私人、回報、管理、帳戶與分享內容頁維持 noindex。

手動瀏覽器驗收：以 `zh-TW`、`en-US`、不支援語言測試新的無痕視窗；雙向切換語言並重新載入；開啟 `/slug` 與 `/slug+`；並在窄版手機寬度檢查切換器。
