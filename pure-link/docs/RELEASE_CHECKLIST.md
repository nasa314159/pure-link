## C. 發布順序

1. 建立 staging 資源與秘密設定。
2. 套用遠端資料庫 migration。
3. 部署 staging 並完成完整驗收。
4. 檢查隱私聲明與實際供應商設定一致。
5. 建立正式備份與回復方式。
6. 部署正式環境，做短時間 smoke test。
7. 才對外公開網址與原始碼。

若任何寫入防護秘密缺失，服務應維持讀取可用、公開寫入回覆 503；不要為了趕上線而繞過保護。
